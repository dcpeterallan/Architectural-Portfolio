# Peter Allan Dela Costa — Architectural Portfolio

A responsive architectural portfolio website built from the professional profile and project history listed on Peter Allan Dela Costa's LinkedIn profile.

## Portfolio contents

- Professional introduction and BIM/architecture capabilities
- 21 documented projects across industrial, logistics, residential camps, healthcare, commercial, infrastructure, and landscape work
- Experience and selected BIM/architecture certifications
- Filterable project catalogue
- Responsive, accessible, dependency-free HTML/CSS/JavaScript
- GitHub Pages deployment workflow

## Project imagery

The first release intentionally uses typographic project covers instead of unrelated stock photography. Replace these covers with authorized project drawings, renders, diagrams, and photographs as they become available.

Suggested asset structure:

```text
assets/
  projects/
    ebara-elliot/
    nupco-asir/
    qiddiya-camps/
    ...
```

Before publishing project visuals, confirm client approval, confidentiality requirements, and image ownership.

## Local preview

Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

A workflow is included at `.github/workflows/pages.yml`. In the repository settings, enable **Pages** and select **GitHub Actions** as the publishing source.
