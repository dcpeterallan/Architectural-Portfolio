Inside each project folder, use:

```text
hero.jpg          Main project cover or best perspective
case-study.pdf    Full project PDF
01.jpg            Additional perspective
02.jpg            Additional perspective
revit.jpg         Revit model view
navisworks.jpg    Navisworks coordination view
plan.jpg          Selected plan
section.jpg       Selected section
detail.jpg        Selected technical detail
```

The current homepage automatically looks for `hero.jpg`. The project PDF button automatically looks for `case-study.pdf`.

## Recommended image preparation

- JPG or WebP
- Landscape format
- 2000–3000 px wide for perspectives
- 1600–2200 px wide for plans, diagrams, and software screenshots
- Keep each image ideally below 1.5 MB
- Remove confidential drawing stamps, project data, usernames, model paths, and issue information
- Confirm client permission before publishing

## Recommended PDF preparation

- A4 or A3 landscape
- Optimized for screen viewing
- Ideally below 15 MB
- Include only approved and non-confidential material
- Clearly state your role and contribution

## Suggested case-study sequence

1. Project title and hero perspective
2. Project facts and personal role
3. Design brief or project challenge
4. Site or planning response
5. Revit model development
6. Navisworks coordination and issue resolution
7. Plans, sections, elevations, or key details
8. Final perspectives or completed-project photographs
9. Responsibilities, software, and lessons learned
